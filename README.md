# SummerProject_Server

여름방학 프로젝트 서버용 레포지토리입니다.

유명 해외 게임 **King of Thieves**에서 영감을 받아 비동기식 멀티플레이 게임을 제작하고 있습니다.

플레이어는 서로가 설계한 집을 약탈하여 자원을 획득할 수 있으며, 자신의 자원을 지키기 위해 다양한 함정을 설치하고 방 구조를 설계해야 합니다.
