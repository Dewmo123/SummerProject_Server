# SummerProject_Server

여름방학 프로젝트 서버용 레포지토리입니다.

유명 해외 게임 **King of Thieves**에서 영감을 받아 비동기식 멀티플레이 게임을 제작하고 있습니다.

플레이어는 서로가 설계한 집을 약탈하여 자원을 획득할 수 있으며, 자신의 자원을 지키기 위해 다양한 함정을 설치하고 방 구조를 설계해야 합니다.

## 개발 기록 (2026.08.05 ~ 2026.08.09)

### 2026.08.05

- 게임 서버 모델을 `DTOs`, `Datas`, `Entities`로 구분하고 관련 컨트롤러·서비스의 파일 구조와 네임스페이스를 정리했습니다.
- 캐릭터, 재화, 스테이지 API의 비동기 처리와 오류 응답을 정비하고, 스테이지 입장·완료 및 보상 지급 로직의 트랜잭션 처리를 강화했습니다.
- 유저별 방 중복 방지, 캐릭터 레벨·경험치와 재화의 유효 범위 검사, 유저 데이터 외래 키, 스테이지 획득 경험치 기록을 위한 데이터베이스 마이그레이션을 추가했습니다.
- 공용 Persistence 모델의 소유 관계를 정리하고, 빌드 시 코드 분석 및 경고 오류 처리를 적용했습니다.

### 2026.08.06

- `GET /api/user-room/me` 내 방 조회 API와 `UserRoomService`를 추가했습니다.
- 방 업로드 시 맵 존재 여부, 함정 종류·좌표·중복 배치·회전값을 검증하고 기존 방을 갱신할 수 있도록 개선했습니다.
- 게임 서버와 로그인 서버를 각각 빌드·게시한 뒤 원격 서버에 전송하고 재시작하는 GitHub Actions 자동 배포 워크플로를 추가했습니다.
- 스테이지 데이터와 API 응답 구조를 수정하고, 모델 명칭을 `DTO`, `Data`, `Entity` 기준으로 통일했습니다.
- 자동 배포 구조에 맞춰 기존 테스트 프로젝트와 CI 워크플로를 정리했습니다.

### 2026.08.07

- 리프레시 토큰 엔티티, 설정, 마이그레이션 및 서비스 로직을 추가했습니다.
- 로그인 및 개발용 로그인 응답에 액세스 토큰과 리프레시 토큰의 만료 정보를 함께 반환하도록 변경했습니다.
- `POST /api/account/refresh` 토큰 갱신 API와 `POST /api/account/logout` 세션 종료 API를 추가했습니다.
- 토큰 원문 대신 SHA-256 해시를 저장하고, 토큰 회전·재사용 감지·토큰 패밀리 폐기를 적용했습니다.
- 로그인 서버 자동 배포 경로를 수정했습니다.

### 2026.08.08

- 리프레시 토큰 요청 모델의 필수값 검증 속성을 수정했습니다.
- 리프레시 토큰 해시 조회 시 발생하던 `ReadOnlySpan` 관련 비교 오류를 수정했습니다.

### 2026.08.09

- 액세스 토큰의 기본 만료 시간을 15분에서 60분으로 조정했습니다.
